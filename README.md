# 线性 SVM 水面分割

模式识别课程作业：用线性 SVM 对航拍图像做二值语义分割，区分水面与非水面。

同一份样本、特征和超参数分别用**原问题**和**对偶问题**两种方式求解，比较训练耗时、目标函数值以及两种解得到的分割结果。

## 环境

- Python 3.11
- 依赖见 `requirements.txt`（numpy、scipy、Pillow）；采样窗口使用 Python 自带的 Tkinter

```powershell
python -m pip install -r requirements.txt
```

## 数据准备

程序从**本目录的上一级**读取输入图像：

```
上级目录/
├── 00000341.jpg     # 输入航拍图
├── output/          # 运行后自动生成
└── Code/            # 本仓库
```

即把 `00000341.jpg` 放到克隆下来的仓库目录的父级目录中。

## 运行

```powershell
python main.py
```

运行后会弹出采样窗口：

- 左键选择**水面**像素（青色），右键选择**非水面**像素（红色）
- 右侧显示两类样本数量，两类都选好后点击「确定」开始训练；直接关闭窗口则取消运行
- 图片按屏幕大小缩放显示，采样坐标会换算回原图；同一点重复点击只更新标签

建议在不同位置多选一些点，覆盖水面的亮暗变化、屋顶、树木、道路和船只。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `main.py` | 依次训练两种 SVM，分割整图并比较结果 |
| `svm_primal_image_seg.py` | 直接优化原问题中的 w、b、松弛变量 |
| `svm_dual_image_seg.py` | 优化对偶问题中的 alpha，再计算 w、b |
| `svm_image_utils.py` | 采样、特征提取、标准化与结果保存 |
| `tune.py` | 鼠标分别选择训练与验证样本，比较 9 组参数 |

运行时在上级目录的 `output/` 下生成：

- `primal_mask.png`、`dual_mask.png`：两种解法的二值分割图（水面为 255）
- `compare.png`：原图与分割结果对比
- `samples.png`、`samples.csv`：采样点及其在原图中的坐标与标签
- `metrics.json`：耗时、目标值、参数与两种结果的一致率

## 方法要点

**特征（7 维）**：R、G、B，除以 RGB 总和后的三个颜色分量，以及 21×21 邻域的灰度标准差。归一化用的均值和标准差只由训练像素统计，再应用到整张图。

**软间隔**：颜色特征存在重叠，硬间隔不可分，因此使用带松弛变量的软间隔形式，惩罚参数 `C = 1.0`。

**原问题**：以 w、b、松弛变量为变量直接最小化

$$\min_{w,b,\xi}\ \frac{1}{2}\lVert w\rVert^2 + C\sum_i \xi_i$$

**对偶问题**：用二次规划求解 alpha，约束为 $0 \le \alpha_i \le C$，再由 alpha 得到 w、b。

**预测**：对每个像素计算 $X w + b$，大于等于 0 判为水面（白），否则为非水面（黑），不做形态学后处理。

这里的「线性」指对提取后的 7 维特征做线性判别，没有使用非线性核。
