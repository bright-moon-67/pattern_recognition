# SVM 水面分割

模式识别课程作业：用线性和 RBF 核 SVM 对航拍图像做二值分割，区分水面与非水面。

一次框选样本后，主程序依次调用原空间线性 SVM、对偶空间线性 SVM 和 RBF 核 SVM，三种方法共用相同的样本、特征及惩罚系数。在 `output/outputend` 中输出三张不带文字的原尺寸二值图，每次运行覆盖同名图片。

## 环境

- Python 3.11
- 依赖见 `requirements.txt`（numpy、scipy、Pillow）；采样窗口使用 Python 自带的 Tkinter

```powershell
python -m pip install -r requirements.txt
```

## 数据准备

程序从**本目录的上一级**读取输入图像：

```
上级目录/
├── 00000341.jpg     # 输入航拍图
├── output/          # 运行后自动生成
└── Code/            # 本仓库
```

即把 `00000341.jpg` 放到克隆下来的仓库目录的父级目录中。

## 运行

```powershell
python main.py
```

运行后会弹出采样窗口：

- 按住左键拖动，框选**水面**区域（青色）；按住右键拖动，框选**非水面**区域（红色），松开完成一个矩形
- 可以框选多个区域；同类区域合并，重叠处以最后一次框选的类别为准
- 每个框单独随机抽取最多 40 个像素，不足 40 个时全部选取，大框不会占用小框的名额；窗口圆点显示实际抽中的像素，右侧显示去重后的两类样本数量
- 两类都框选好后点击「确定」开始训练；图片会按屏幕大小缩放，矩形位置会换算回原图

测试图片为 1000×1000，共 100 万个像素。框选后抽取的像素用于训练，训练完成后仍然预测整幅图片的全部像素。

建议在不同位置框选多个小区域，覆盖水面的亮暗变化、屋顶、树木、道路和船只，每个框尽量只包含同一类别。`svm_image_utils.py` 中 `select_samples` 的 `count=40` 控制每个框最多抽取多少像素，随机种子固定为 0。例如河水、非河水各框 6 个互不重叠的区域，每框至少 40 个像素，则两类各有 240 个训练样本。

每个仍有有效像素的框都会参与采样；重叠处以最后一次标注的类别为准，重复抽中的像素只保留一次。如果一个旧框被另一类别的框完全覆盖，它的旧类别标注就被替换，不再保留旧类别样本。新增框后窗口会重新显示最终样本点。

保存的样本坐标仍为实际抽取的像素坐标，三种方法由主程序统一调用，共用这一次框选结果。

## 文件说明

`svm_rbf_image_seg.py` 只保留核函数、训练和分批预测函数，由 `main.py` 调用，不再单独运行。参数统一在 `main.py` 中设置：`C=1.0`、`gamma=0.1`、`window=21`。

| 文件 | 用途 |
| --- | --- |
| `main.py` | 统一训练三种方法，输出三张二值图 |
| `svm_primal_image_seg.py` | 直接优化原问题中的 w、b、松弛变量 |
| `svm_dual_image_seg.py` | 优化对偶问题中的 alpha，再计算 w、b |
| `svm_image_utils.py` | 采样、特征提取、标准化与结果保存 |
| `svm_rbf_image_seg.py` | RBF 核非线性 SVM 的训练和分割 |

运行时仅在上级目录的 `output/outputend/` 下生成：

- `原空间线性SVM.png`
- `对偶空间线性SVM.png`
- `RBF非线性SVM.png`
- `算法耗时.csv`：三种方法的训练时间、整图预测时间和总时间（秒）
- `线性SVM对比指标.csv`：目标值、对偶间隙、权重差异、分割一致率等

三张图均为原图尺寸的黑白图，河水为白色，其他区域为黑色，不添加标题、文字或边框。每次运行覆盖同名文件，不追加序号，不再生成拼接图或采样 CSV。

计时使用 `perf_counter`，总时间为训练时间与整图预测时间之和，不包含读图、人工框选、公共特征提取、指标计算和文件保存。训练时间包含求解器内部的矩阵构建；预测时间包含分类与转换为 0/255。记录的是本次运行的单次耗时。

线性原问题目标为 `P(w,b)=0.5*w@w+C*sum(max(0,1-y*(X@w+b)))`，原问题法和对偶法的解分别得到 P1、P2；线性对偶目标为 `D=sum(alpha)-0.5*w2@w2`。同时记录 P1-D 与 P2-D，并附上对偶约束误差，辅助判断数值结果。Gap 保留原始差值，不取绝对值；数值误差可能造成极小的负值。权重差异为 `||w1-w2||₂`，分割一致率以百分数保存。上述解的一致性指标仅比较两种线性方法，不能将 RBF 的目标与线性目标直接相减。分割一致率不代表分割准确率。

## 方法要点

**特征（7 维）**：R、G、B，除以 RGB 总和后的三个颜色分量，以及 21×21 邻域的灰度标准差。归一化用的均值和标准差只由训练像素统计，再应用到整张图。

**软间隔**：颜色特征存在重叠，硬间隔不可分，因此使用带松弛变量的软间隔形式，惩罚参数 `C = 1.0`。

**原问题**：以 w、b、松弛变量为变量直接最小化

$$\min_{w,b,\xi}\ \frac{1}{2}\lVert w\rVert^2 + C\sum_i \xi_i$$

**对偶问题**：用二次规划求解 alpha，约束为 $0 \le \alpha_i \le C$，再由 alpha 得到 w、b。

**线性预测**：对每个像素计算 $X w + b$，大于等于 0 判为水面（白），否则为非水面（黑），不做形态学后处理。

这里的「线性」指对提取后的 7 维特征做线性判别，没有使用非线性核。

**非线性预测**：将内积替换为 RBF 核，使用核函数加权求和得到分类分数，分批处理整图以减少内存占用。
